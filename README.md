# 📊 Analyse et Segmentation des Clients pour la Décision Marketing

---

## 🎯 Objectif
Ce projet vise à segmenter les clients afin d’optimiser les stratégies marketing grâce à des techniques de Data Mining et de Machine Learning.

---

## 💡 Description
Application web développée avec Streamlit permettant :
- d’explorer et nettoyer les données clients
- d’analyser les comportements d’achat
- de segmenter les clients avec des méthodes avancées
- de générer des insights exploitables pour la prise de décision

---

## ⚙️ Méthodologie

### 1. 📥 Collecte et préparation des données
- Chargement de données (fichier ou exemple)
- Nettoyage et transformation

### 2. 📊 Analyse descriptive
- Statistiques descriptives
- Compréhension des variables

### 3. 📈 Visualisation des données
- Graphiques interactifs
- Analyse du comportement client

### 4. 🤖 Modélisation et prédiction
- Analyse RFM (Récence, Fréquence, Montant)
- Clustering avec K-Means
- Prédiction du segment client
- Extraction de règles d’association (Apriori)

### 5. 📌 Résumé et interprétation
- Synthèse des segments
- Recommandations marketing

---

## 🧠 Technologies utilisées
- Python
- Pandas
- Scikit-learn
- Plotly
- Streamlit
